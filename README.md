# Behavioural-nudges-extracurricular
Behavioural Economics in Action: Nudges to Boost Extracurricular Participation Among Students

This project explores how behavioural economics and strategic nudges can encourage students to participate more actively in extracurricular activities and promote holistic development. It examines key behavioural barriers such as status quo bias, social proof, and present bias, which can influence students' decisions to engage beyond academics.

The project proposes practical interventions including default enrolment, peer ambassador programmes, participation-based rewards, extracurricular showcases and competitions, parental engagement, and awareness of long-term benefits. It also considers broader challenges such as limited infrastructure, parental emphasis on academics, unequal access, and gender disparities.

Overall, the project highlights how thoughtfully designed behavioural interventions can help educational institutions create a more balanced, inclusive, and engaging environment, while supporting students in developing skills such as communication, teamwork, confidence, leadership, and problem-solving.
Exploring behavioural nudges, student decision-making, and data-driven interventions to increase extracurricular participation and support holistic student development.
